# Бушуев Никита БАС-1 Лабораторная №1

## Задача 1

### Текст задачи

Получить список из последних цифр чисел, содержащихся в исходном списке
Решить задачу из лабораторной работы №2 (Задание 1. List.map) для
последовательности


### Алгоритм решения

1.Запросить у пользователя количество элементов n  
2.Создать пустой список для хранения чисел  
3.В цикле от 1 до n запросить ввод числа, проверить корректность и добавить в список  
4.Преобразовать список в последовательность  
5.Для каждого элемента последовательности вычислить последнюю цифру по формуле |x| % 10  
6.Вывести все полученные последние цифры через пробел

### Тестирование

Скриншоты результата работы программы

## Задача 2

### Текст задачи

Найти сумму тех элементов списка, которые оканчиваются на заданную цифру
Решить задачу из лабораторной работы №2 (Задание 2. List.fold) для
последовательности

### Алгоритм решения

1.Запросить у пользователя количество элементов n  
2.В цикле от 1 до n запросить ввод числа, проверить корректность и добавить в список  
3.Запросить у пользователя цифру d от 0 до 9, при ошибке повторять запрос  
4.Инициализировать переменную суммы = 0  
5.Для каждого числа из списка вычислить последнюю цифру |x| % 10 и если она равна d, добавить число к сумме  
6.Вывести полученную сумму

### Тестирование

Скриншоты результата работы программы

## Задача 3

### Текст задачи

Вывести пути ко всем файлам, не являющимся текстовыми (имеют
расширение, отличное от txt), в указанном каталоге и его подкаталогах.

### Алгоритм решения

1.Запросить у пользователя путь к каталогу  
2.Проверить существует ли каталог, если нет - вывести ошибку и завершить программу  
3.Создать рекурсивную функцию которая получает все файлы в текущей папке, фильтрует их по расширению (оставляет только не .txt), затем получает все подпапки и для каждой вызывает саму себя  
4.Запустить эту функцию с указанным пользователем путем  
5.Вывести все найденные файлы по одному и посчитать их количество

### Тестирование

Скриншоты результата работы программы
